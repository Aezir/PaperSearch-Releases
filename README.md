# 纸页搜索 · 官方发行

轻量个人 Android 搜索页。透明悬浮界面，搜索引擎快捷切换，本机历史、通讯录和短信匹配。

[下载最新安装包](https://github.com/Aezir/PaperSearch-Releases/releases/latest) · [版本信息](update.json)

此仓库仅公开官方 APK、更新元数据和许可；源码保持私有。Android 8 以上可安装，真正的背景模糊需要 Android 12 以上且设备启用跨窗口模糊；其他设备显示无边框透明界面。安装和更新均由 Android 系统最终确认。

在应用设置中点击“检查更新”即可检查、下载并安装新版。联网仅在主动检查或下载更新时进行，不上传查询、联系人、短信或设备标识。联系人和短信需要用户授权；手机系统和安装来源仍可能限制实际读取。
